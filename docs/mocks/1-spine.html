What's the difference between HRV SDNN and RMSSD?

          
14:39

            
Claude
              
Both measure the variation between heartbeats. SDNN is the spread across the whole window, so it picks up slow changes too — breathing, posture, the day. RMSSD looks only at the gap between one beat and the next, so it tracks the fast, parasympathetic side. Apple Health shows SDNN, which is why yours reads 41 ms.
